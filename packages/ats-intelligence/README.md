# ATS Intelligence

`@career-companion/ats-intelligence` deterministically models a transparent automated screening gate before human recruiter evaluation.

It produces immutable, explainable `ATSPipeline`, `ATSParsing`, `ATSMatching`, `ATSScreening`, and `ATSDecision` artifacts. It does not simulate proprietary ATS vendors, optimize candidates, rewrite resumes, invoke AI, render documents, persist state, or access infrastructure.
