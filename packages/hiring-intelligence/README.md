# Hiring Intelligence

`@career-companion/hiring-intelligence` models the deterministic hiring pipeline used by human evaluators.

It produces immutable, explainable hiring artifacts for `HiringPipeline`, `RecruiterEvaluation`, `HiringManagerEvaluation`, `InterviewEvaluation`, and `HiringDecision`. It does not perform candidate optimization, AI execution, rendering, persistence, infrastructure, repositories, or application runtime behavior.
