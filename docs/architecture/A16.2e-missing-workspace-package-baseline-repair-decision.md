# A16.2e - Missing Workspace Package Baseline Repair Decision

## 1. Executive Summary

A16.2e confirms the A16.2d workspace-scope contradiction: `packages/career-artifacts` and `packages/explainability` are absent from `HEAD` as source package directories, while committed manifests, committed source imports, committed tests, and `HEAD:pnpm-lock.yaml` already reference both workspace packages.

The current untracked implementations match the committed package names, expose the symbols required by committed consumers, follow the repository package shape, include tests, and do not show TODO/FIXME/HACK/placeholder/stub/debug markers in static search.

Local Git history does not show either package path ever committed, so the root cause is best classified as committed dependency/source references without committed package source, not an accidental deletion visible in local history.

Recommended repair model: Model A - add the missing package source as a prerequisite shared workspace baseline repair, subject to approval and validation. This should be separate from the Portfolio Workspace A10-A16 release-candidate commits.
